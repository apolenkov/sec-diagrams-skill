# Правила общения

Обсуждайте работу по существу. Уважайте право участников задавать вопросы и выражать несогласие.
Травля, угрозы, дискриминация и публикация чужих личных данных без согласия недопустимы.

О нарушениях сообщайте владельцу проекта через GitHub приватно. Владелец может удалить
нарушающие правила материалы или ограничить доступ к обсуждениям.
