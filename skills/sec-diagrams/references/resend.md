# Повторная проверка пакета

Составьте перечень затронутых листов и связей. Для каждой правки запишите id
ячейки и причину изменения. Агент вносит правки в рабочей копии, человек вписывает значения
в копию для отправки в draw.io. Сопоставьте исправления с журналом правил МЭ.
[NIST SP 800-41 Rev. 1, § 5.5](https://nvlpubs.nist.gov/nistpubs/Legacy/SP/nistspecialpublication800-41r1.pdf#page=41)

## Номера связей

Оставьте номера действующих связей. Если связь удалена, добавьте ее номер в
`sheets[].retired`. Ключ в этом объекте совпадает с именем страницы внутри
draw.io. Новую связь обозначьте числом после всех использованных и снятых
номеров. Например, на листе с 1, 2, 4, 5 и снятым 3 новая связь получит 6.

```json
{
  "file": "l3-2.drawio",
  "level": "L3-2",
  "topic": "Архив",
  "retired": { "Запись измерений": [3] }
}
```

## Точечное изменение

- Для замены подписи в рабочей копии используйте `text set <лист> <id> <текст>`.
  Ограничьтесь ячейками из перечня. Массовый `fix --safe` применяет исправления
  ко всему файлу.
- Новую стрелку добавьте в редакторе draw.io. Закрепите концы на двух узлах и
  поставьте промежуточные точки, если линия задевает блок или накладывается
  на другую связь. [Документация draw.io, Work with waypoints on connectors](https://www.drawio.com/docs/manual/connectors/waypoints-connectors/)
- Поместите номер и службу рядом с линией. Если правите XML рабочей копии,
  задайте для обеих подписей `parent` с id связи. Относительная координата
  `x` от `-1` до `1` задает положение вдоль маршрута. Добавьте в перечень строку
  с номером, назначением и транспортом согласно `notation.md`.
- Обновите ссылку `link` в YAML, если изменилось правило МЭ. Перестройте лист
  командой `rules --force` и повторите `check`. Сверьте SD-N01 с номерами
  текущих и удаленных связей. Просмотрите места изгиба и пересечений на
  печатном листе (SD-G01). [Документация draw.io, Print a diagram](https://www.drawio.com/docs/manual/export/print-diagram/)
