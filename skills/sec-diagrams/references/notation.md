# Обозначения

Палитра примера и список шрифтов хранятся в [профиле по умолчанию](../config/profiles/default.json).
Сохраняйте значения цветов между версиями схемы. При проверке `SD-L02` сопоставляет цвет с профилем.

| Цвет | Поток |
| --- | --- |
| `#000000` | Существующая связь без направления |
| `#237a53` | Доступ приложения |
| `#2867a6` | Поток между сегментами |
| `#ad3b31` | Управление |
| `#754bb0` | Поток внутри сегмента |
| `#64748b` | Запрещенная связь с крестом, без номера |

- Стрелку ведите от инициатора к сервису. При двух независимых инициаторах покажите две связи.
- Ставьте номер в рамке на линии, протокол рядом с номером, например `HTTPS (443/TCP)`.
  Начинайте строку перечня с того же номера.
- Используйте рамки зон для границ доверия, заливку объекта для статуса. В легенде поясните
  цвета, типы линий и заливки, которые есть на листе.
- Для ортогональных переходов профиль ожидает `rounded=1; jumpStyle=arc; jumpSize=12`.
  У ранее отправленных листов меняйте только нужную ячейку командой `style set`.
- Для неизвестного адреса в рабочей копии используйте `XX.XX.XX.XX`. Для незаполненного поля
  используйте `[поле]`. Порядок заполнения приведен в [справочнике копий](copies.md).
