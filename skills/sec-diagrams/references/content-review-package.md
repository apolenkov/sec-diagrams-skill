# Изменения правил

- [ ] Сопоставьте изменения правил с журналом и проверьте, указана ли причина каждого
  изменения. [NIST SP 800-41 Rev. 1, § 5.2.2](https://nvlpubs.nist.gov/nistpubs/Legacy/SP/nistspecialpublication800-41r1.pdf#page=39), [NIST SP 800-41 Rev. 1, § 5.5](https://nvlpubs.nist.gov/nistpubs/Legacy/SP/nistspecialpublication800-41r1.pdf#page=41)
- [ ] Для проверки конфигурации предусмотрите допустимый и запрещенный трафик.
  Запишите ожидаемый результат для каждого сценария. [NIST SP 800-41 Rev. 1, § 5.3](https://nvlpubs.nist.gov/nistpubs/Legacy/SP/nistspecialpublication800-41r1.pdf#page=40)
- [ ] Периодически пересматривайте политику МЭ. Отмечайте правила, которые больше
  не нужны, и новые требования к фильтрации. [NIST SP 800-41 Rev. 1, § 5.5](https://nvlpubs.nist.gov/nistpubs/Legacy/SP/nistspecialpublication800-41r1.pdf#page=42)
