# Проверка сетевой политики

- Найдите границу между сетями с разной политикой и точки, в которых фильтруется
  трафик. Для каждого альтернативного пути проверьте, где действует та же политика. [NIST SP 800-41 Rev. 1, § 3.1](https://nvlpubs.nist.gov/nistpubs/Legacy/SP/nistspecialpublication800-41r1.pdf#page=23)
- Начните с запрета по умолчанию. Для каждого разрешения проверьте, какой
  рабочий сценарий требует соединения и можно ли сузить его до конкретных адресов,
  транспорта и портов. [NIST SP 800-41 Rev. 1, § 4, 4.1.3](https://nvlpubs.nist.gov/nistpubs/Legacy/SP/nistspecialpublication800-41r1.pdf#page=28)
- Если фильтр учитывает состояние соединения, отличайте новый сеанс в обратном
  направлении от ответного трафика уже разрешенного сеанса. [NIST SP 800-41 Rev. 1, § 2.1.2](https://nvlpubs.nist.gov/nistpubs/Legacy/SP/nistspecialpublication800-41r1.pdf#page=14)
