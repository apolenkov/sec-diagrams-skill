# Навык sec-diagrams

Начните с [SKILL.md](SKILL.md). В [шаблонах](content/templates/) есть четыре листа draw.io,
манифест и YAML с правилами межсетевого экрана для системы сбора телеметрии.

Команда `pack <папка>` создает папку с суффиксом `-обзор`. В нее входят общий PDF
`Обзор__Служба__N.pdf` и папка `схемы/` с исходниками сетевых листов.
Чтобы добавить записку, укажите `--with-letter`. Чтобы включить карту фильтрации в PDF
и в `схемы/`, укажите `--with-rules`. Порядок флагов свободный.

Из этого каталога выполните `npm ci`, `npm run typecheck` и `npm test`. Тесты PDF используют
синтетические документы и пропускаются без MuPDF.js. Для интеграционных тестов экспорта нужен
draw.io Desktop и переменная `SD_DRAWIO_IT=1`.

Тесты подсказок проверяют команды через `zsh -f -n -c`.
