# Вклад в проект

Для сообщения об ошибке приложите минимальный пример на вымышленных данных, команду и результат.
Используйте адреса TEST-NET и домены example.org, .test или .invalid.

Перед отправкой изменений запустите `npm ci`, `npm run typecheck` и `npm test`. Для изменений
PDF запустите тесты и с подключенным MuPDF. После изменения генератора обновите шаблоны командой
`node skills/sec-diagrams/tools/templates.ts --write`.

Открывая запрос на слияние, укажите, что изменилось для пользователя и как это проверить.
Ваш вклад распространяется на условиях [MIT](LICENSE).
